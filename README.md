🤖 Multi-Agent AI Chatbot(LEXI)
Multi-Agent AI Chatbot is an advanced AI system that uses multiple intelligent agents working together to understand, process, and respond to user queries efficiently. It is built using Generative AI, Retrieval-Augmented Generation (RAG), and Natural Language Processing (NLP) to deliver accurate and context-aware responses. The project includes a modern and responsive UI built with React.js and Tailwind CSS, along with a powerful backend using FastAPI and Python. It also integrates tools like LangChain/LangGraph, PostgreSQL, and ChromaDB for memory and knowledge retrieval. The system is designed to be scalable, secure, and extensible, with future enhancements planned such as voice interaction, autonomous agents, and multi-LLM support.
